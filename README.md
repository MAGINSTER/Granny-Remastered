# Granny-Remastered
Granny Remaster - сделан на основе игры Granny и по большей части переделан под свой стиль и возможности. На карте имеется две концовки: побег через дверь и смерть. Чтобы сбежать через дверь требуется находить различные предметы на карте, к примеру: ключи, листы с паролем, ломы и т.д.
